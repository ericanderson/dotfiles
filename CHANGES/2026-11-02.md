# Chezmoi Dotfiles Changes - November 2, 2026

## Summary

Captured the `ea-private` Claude Code plugin in `dot_claude/private_settings.json.tmpl`.
It had only ever been enabled in the deployed `~/.claude/settings.json`, so the next
`chezmoi apply` would have disabled it and removed its marketplace.

## Changes

### 1. Added the `ea-private` Plugin and Marketplace

`dot_claude/private_settings.json.tmpl`:

- `enabledPlugins`: added `"ea@ea-private": true` (the `ea:*` skills such as
  `lookup-context` and `weekly-review`).
- `extraKnownMarketplaces`: added `ea-private`, a git source at
  `https://github.com/ericanderson/private-claude-plugins.git`.

Both sit where Claude Code had put them in the deployed file, so it doesn't reorder
them on its next write.
