# Chezmoi Dotfiles Changes - November 17, 2026

## Summary

Moved the `claude-log` skill out of dotfiles and into the `ea-codes` plugin
(ericanderson/claude-ea-codes), where it ships together with the `log-inspector` agent
it launches.

## Changes

### 1. Removed the `claude-log` Skill

- `dot_claude/skills/claude-log/SKILL.md`: deleted. The skill is now
  `ea-codes:claude-log`.
- `.chezmoiremove`: `.claude/skills/claude-log`, so `chezmoi apply` deletes the
  deployed copy. Without this, the old skill would keep loading next to the plugin's.
- `dot_claude/skills/boss/standards.md`: workers log with `ea-codes:claude-log`.

## Verification

None in this repo. `claude plugin validate` passes on the plugin side.

## Known Issues

- The Logging rule in `~/.claude/CLAUDE.md` still names `claude-log`. That file is not
  managed here (`.chezmoiignore.tmpl` ignores `.claude/**/*` except a few folders), so
  it has to be edited by hand.
- Merge and pull the plugin change before applying this one, or no claude-log skill is
  available in between.
