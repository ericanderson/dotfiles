# Chezmoi Dotfiles Changes - November 24, 2026

## Summary

The Forgejo domain in the Claude Code sandbox's network allowlist is now
encrypted like the other homelab entries, so the public settings template no
longer names an internal domain. The private auto-mode entries name both Macs
instead of calling one of them "this Mac", and the `wshobson/agents`
marketplace is declared under its real name.

## Changes

### 1. Sandbox Homelab Domains Moved Into the Encrypted File

- `.private/claude.json.age`: new `sandboxAllowedDomains` list holding the Forgejo
  domain, which `dot_claude/private_settings.json.tmpl` listed in plain text in
  `sandbox.network.allowedDomains` since 77081f5.
- `dot_claude/private_settings.json.tmpl`: splices that list in at the top of
  `allowedDomains` when the age identity exists, and defaults it to empty
  otherwise. A machine without the key gets only the GitHub domains, so sandboxed
  commands there cannot reach the Forgejo.

The domain is still in git history. It is not rewritten: the repo has been
public with it, and the name alone grants nothing.

### 2. Private Auto-Mode Entry Names Both Macs

- `.private/claude.json.age`: the internal-services environment entry called the
  first Mac "this Mac", which was wrong for sessions on the second Mac. It now
  lists both Macs by name.

### 3. `claude-code-workflows` Marketplace Key

- `dot_claude/private_settings.json.tmpl`: the `wshobson/agents` marketplace was
  declared as `agents`, but its `marketplace.json` names it
  `claude-code-workflows`, which is how Claude Code registers it. The key now
  matches.

## Verification

- With the key, `chezmoi diff ~/.claude/settings.json` shows only the marketplace
  key rename and the reworded environment entry. `allowedDomains` renders
  unchanged.
- With the identity check forced off, the template renders valid JSON with the
  five GitHub domains, two `autoMode.allow` and two `autoMode.environment`
  entries, and no internal names.
- No plain-text internal domain, tailnet name or IP remains in the source tree
  (`grep -rli` outside `.git`).
