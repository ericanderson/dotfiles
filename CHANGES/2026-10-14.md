# Chezmoi Dotfiles Changes - October 14, 2026

## Summary

Added a user-level `boss` skill for orchestrating several Claude Code sessions, each in
its own herdr worktree, from one "Boss" session per repo. Narrowed claude-log's "don't
log" rule to Agent-tool subagents, so herdr workers log their own work.

## Changes

### 1. Added the `boss` Skill

New `dot_claude/skills/boss/`, deployed to `~/.claude/skills/boss/`:

- **`SKILL.md`**: the Boss process. It covers herdr preconditions, setup (brief, worktree,
  agent, tracker, memory), messaging, the plan / review / final-check gates, shared
  resources, reporting, logging and cleanup.
- **`standards.md`**: the generic brief that the Boss copies to `orch/common.md` for
  workers. Repo-specific rules belong in each repo's CLAUDE.md, in a "Working with
  agents" section.

The skill doesn't assume a forge or a default branch name. It uses `origin/<default>`
(`origin/HEAD`) and the forge CLI the repo's CLAUDE.md names. The review roster lists
only plugin reviewers that every repo has, plus whatever reviewers the repo itself
defines.

### 2. Narrowed claude-log's Subagent Rule

`dot_claude/skills/claude-log/SKILL.md`: the "only the top-level agent logs" rule now
applies only to subagents launched with the Agent tool inside one session. A separate
session in its own pane, such as a herdr worker briefed by a Boss session, is top-level
and logs its own work. The "clearest tell" sentence no longer treats any assignment
written by another agent as making you a subagent.
